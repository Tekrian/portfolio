La météo à votre adresse

Application web qui affiche la météo d'une adresse saisie par l'utilisateur, une rue précise ou simplement une ville. Elle enchaîne deux API : celle de l'IGN pour obtenir les coordonnées de l'adresse, puis OpenWeatherMap pour récupérer la météo à cet endroit.

Ce que j'ai appris

Ce projet m'a appris à enchaîner des requêtes HTTP asynchrones avec fetch et async/await, la seconde dépendant du résultat de la première. J'ai aussi appris à lire la documentation d'une API et à exploiter ses réponses JSON, à organiser l'application en classes avec une seule responsabilité chacune, et à configurer webpack pour empaqueter le projet.

Fonctionnalités
  • Recherche par adresse précise (rue, numéro) ou par ville
  • Température, ressenti, description, humidité et vent
  • Gestion des erreurs : champ vide, adresse introuvable, problème réseau
  • Interface responsive
  • JavaScript
  • API REST

Projet IUT · Projet individuel

Calculateur de temps de route

Application de bureau en C++ et Qt qui calcule le trajet le plus rapide entre deux villes françaises et affiche le chemin sous forme de liste de villes (ville 1 -> ville 2 -> … -> ville n). Elle compare aussi les temps de trajet dans un tableau et trouve le meilleur emplacement pour un dépôt. Les données couvrent 100 villes et 542 liaisons routières.

Ce que j'ai appris

Ce projet m'a fait relier les mathématiques, la programmation en C++ et la création d'une interface avec Qt. Les temps de trajet sont stockés dans un graphe pondéré : chaque ville est un sommet et chaque route a pour poids sa durée. Le cœur du travail a été le choix de l'algorithme. J'ai retenu Floyd–Warshall, qui calcule en une seule fois les temps minimaux entre toutes les paires de villes : c'est adapté à une application qui compare beaucoup de trajets. Sa complexité en O(V³) reste raisonnable pour 100 villes, et chaque recherche devient ensuite instantanée. Pour le dépôt, j'ai implémenté deux critères : réduire la somme des temps de trajet, ou réduire le temps du trajet le plus long.

Fonctionnalités
  • Itinéraire le plus rapide, avec les villes traversées
  • Tableau comparatif des temps entre plusieurs villes
  • Tri par nom ou par population, filtre par région
  • Dépôt optimal selon deux critères
  • C++17
  • Qt Widgets
  • Graphes
  • Floyd–Warshall
  • CSV
